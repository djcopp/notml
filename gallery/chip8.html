A CHIP-8 computer inside an ONNX file

The whole machine (CPU, 4 KB of memory, registers, stack, timers and a 64 × 32 screen) is one 200 KB ONNX graph with no control flow. Each call runs a frame of instructions for every console in a batch. Play one, or run a thousand at once.

–consoles
–instructions per second, all consoles
–frames per second (target 60)
–time per model call

Every instruction is decoded and executed with tensor operations: the graph computes what each instruction would do and keeps the one that applies. Bitwise operations are built from division and remainder, since WebGPU in onnxruntime-web has no bitwise kernels. The Python package that builds it is tested against a conventional emulator on hundreds of thousands of random instructions. Source: github.com/djcopp/notml · simulation gallery
